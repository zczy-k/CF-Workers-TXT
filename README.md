# CF-Workers-TXT

**一个跑在 Cloudflare 上的在线笔记 / 网盘。** 一个 `worker.js` 跑在 Workers/Pages 上，文件本体进 R2，
分享口令进 KV —— 不用服务器、不用数据库、不用备案。仓库里还带一个原生客户端，装到手机/桌面上就不用开浏览器了。

```
worker.js  ──►  Cloudflare Workers / Pages  ──►  R2（文件） + KV（分享口令 / 登录态）
    ▲
    │ /<ADMIN_UUID>/api
    │
client/（原生客户端）
自己画像素，不套 WebView
```

| 你想要的 | 用这个 | 说明 |
| --- | --- | --- |
| 一个自己的在线笔记 / 网盘（浏览器就能用） | **`worker.js`** | 主力形态，功能最全，见本文 |
| 手机上像 App 一样打开、不依赖浏览器 | **`client/`** | Flutter 原生渲染，不碰浏览器；只吃 `worker.js` 现有接口，服务端不用改。见 [`client/README.md`](./client/README.md) |

> **想把某个网站包成自己的 App？** 那不归这个仓库管，去隔壁
> [`zczy-k/CF-WebShell`](https://github.com/zczy-k/CF-WebShell) —— 一个通用的 Android / Windows 网页壳，
> 名字、图标、站点都可配，跟本项目**没有任何代码依赖**。
>
> 本项目的客户端取舍与踩过的坑写在 [`client/ARCHITECTURE.md`](./client/ARCHITECTURE.md)。
> 本文只讲**服务端怎么部、怎么用**。

## 它长什么样

「左侧文件管理 + 右侧编辑/列表」的布局，接近常见在线笔记工具：

- **左栏**：搜索框（管理端是**全文搜索**：文件名 + 正文；分享页只搜文件名）、一棵**能看清全部内容的目录树**、可拖拽的侧栏宽度（双击分隔条按最长文件名自动撑开）
- **右栏**：编辑器 / 预览 / 列表，按文件类型自动决定怎么显示
- **手机上**：单栏切换、长按多选、返回键按「目录 → 上一页 → 退出」逐级退；支持装到桌面（PWA）
- **分享**：生成只读口令链接，草稿与已发布物理隔离，改了不会立刻影响分享页

打开文件时**按类型自动选择怎么显示**：Markdown 渲染成网页、JSON 折叠成树、CSV 变成表格、
代码高亮、图片/音视频/PDF 直接预览 —— 认不出的格式退回纯文本，**不会出现打不开的文件**。

## 五分钟部署

需要两样 Cloudflare 资源：

| 资源 | 用途 | 绑定变量名（**必须一字不差**） |
| --- | --- | --- |
| **R2 存储桶** | 文件夹与文件本体 | `R2` |
| **KV 命名空间** | 分享口令、登录态、限速计数 | `KV`（可选；不用分享可以不绑） |

### 1. 先开 R2

R2 需要先绑支付方式才能开通（Cloudflare 的硬性要求，免费额度内不扣费）：
右上角头像 → **Billing → Add Payment Method** → 回 **R2 Object Storage → Enable R2**。

R2 每月免费额度：**10GB 存储 / 100 万次写 / 1000 万次读，出口流量永久免费**。超出部分按量计费。

### 2. Workers 版（有域名就用这个）

1. R2 里新建存储桶（例如 `my-drive`，名称只能小写字母 + 数字 + 连字符）
2. **Workers & Pages → KV** 新建命名空间（要分享才需要）
3. **Workers & Pages** 新建 **Worker**（Hello World 模板即可）→ 进在线编辑器
4. 删光默认代码，粘贴本项目 [`worker.js`](./worker.js) 的全部内容 → **部署**
5. **设置 → 绑定** 加两条：`R2 存储桶` 变量名填 **`R2`**；`KV 命名空间` 变量名填 **`KV`**
6. **设置 → 变量** 加 `ADMIN_UUID`（随便一串别人猜不到的字符），**强烈建议再加 `PASSWORD`**
7. 绑定改动必须重新部署才生效 —— **再点一次「部署」**
8. 打开 `https://<worker名>.<你的账户>.workers.dev/<ADMIN_UUID>`
9. 想用自己的域名：**设置 → 域和路由** 里添加

### 3. Pages 版（没有域名就用这个）

1. 同上先开 R2 + 建桶（要分享再加 KV）
2. **Workers & Pages → Pages** 新建项目 → 选「直接上传 / Upload assets」
3. 上传 [`pages.zip`](./pages.zip) → 保存并部署

   > zip 里只有一个 `_worker.js`，它必须和仓库里的 [`worker.js`](./worker.js) **逐字节一致**。
   > 自己改过 worker.js 之后记得重新打包（Windows：把 `worker.js` 复制成 `_worker.js`，右键压缩成 zip）：
   >
   > ```bash
   > python -c "import zipfile; zipfile.ZipFile('pages.zip','w',zipfile.ZIP_DEFLATED).write('worker.js','_worker.js')"
   > ```
4. **设置 → 绑定** 加 `R2`（必填）与 `KV`（可选），变量名必须一字不差
5. **设置 → 变量** 加 `ADMIN_UUID`
6. **重新上传 `pages.zip` 并再部署一次**（让绑定生效，这一步最容易漏）
7. 打开 `https://<pages域名>/<ADMIN_UUID>`

## 本机调试（可选）

不用每改一行就部署到 Cloudflare 再试。仓库里带了一个内存版 R2 / KV，能把**真实的 `worker.js`** 直接跑起来：

```bash
node mock.mjs                                    # → http://127.0.0.1:8787/dev
PORT=9000 ADMIN_UUID=me PASSWORD=pw node mock.mjs
```

数据全在内存里，Ctrl+C 就清空 —— 碰不到你线上任何一个字节。`ADMIN_UUID` 默认是 `dev`。

> 它只做请求 / 响应的翻译，不模拟 Cloudflare 的边缘行为：没有缓存、没有 **10ms CPU** 上限、
> 没有真实客户端 IP。所以限速、超时、大文件相关的分支，本地表现和线上不一样，别拿本地当性能结论。

## 环境变量

| 参数名 | 必填 | 说明 |
| --- | --- | --- |
| **ADMIN_UUID** | ✅ | 管理页入口路径，任意字符串/UUID。`8c3b9f3a-...` 就访问 `/8c3b9f3a-...`。**当成密码看待** |
| **R2** | ✅ | R2 桶绑定，变量名必须填 `R2` |
| **KV** | ❌ | KV 绑定，变量名必须填 `KV`。**分享功能依赖它**，不绑则「分享」不可用，其余正常 |
| **FILENAME** | ❌ | 管理页标题，默认 `CF-Workers-TXT` |
| **PASSWORD** | ❌ | 设置后需要登录，右上角出现「退出」。**强烈建议设置** |
| **SESSION_DAYS** | ❌ | 登录态天数，默认 `30`；`0` = 关浏览器即退出；上限 365 |
| **RATE_LIMIT** | ❌ | 每 IP 每分钟请求上限，默认 `240`，超出 429；`0` 关闭（不建议） |
| **DOWNLOAD_LIMIT** | ❌ | 每 IP 每分钟分享文件直连次数，默认 `60`；`0` 关闭 |
| **INDEX_TEXT_CAP** | ❌ | 全文索引正文总量上限（字节），默认 `1048576`（1MB）。**硬上限 1572864**，填更大会被夹回 |

> 免费版 Worker 单次只有 **10ms CPU**，`INDEX_TEXT_CAP` 不建议超过 2MB；升级付费版（30s CPU）后可放宽。

## 功能

**文件管理**

- 建文件夹、新建文本、上传文件/文件夹、批量删除/移动、打包下载（文件夹也能整包下成 zip）
- 列表按 **名称 / 类型 / 大小 / 修改时间** 排序，偏好记住
- **框选批量选择**（桌面拖框 + `Ctrl`/`Shift` 追加 / 连选）、**长按多选**（手机，0.4 秒进入多选）
- 上传同名文件有比对清单，可选择覆盖 / 跳过 / 保留两份
- **分片上传**：超过 8MB 自动分片、可断点续传；中断后重新选同一个文件会跳过已传分片

**查看与编辑**

- 内置 **159 种扩展名**的识别与渲染（`yaml` `toml` `json` `md` `csv` `js` `ts` `py` `go` `rs` `sql` `sh` …），无扩展名的 `Dockerfile` `README` 也按文本打开
- **编码自动识别**：BOM → 严格 UTF-8 → 前 64KB 采样比对 GB18030 / Big5 / EUC-KR / Shift-JIS / Windows-1252，取替换字符最少的；保存一律写 UTF-8（状态栏提示原编码）
- 超过 **2MB** 的文本不在线打开，提示下载后用本地编辑器（避免浏览器卡死）
- 行号槽在超过 512KB 或 4000 行时自动关闭（防输入卡顿），内容不受影响

**搜索**

- 管理端**全文搜索**：文件名 + 正文，索引存在 R2（`__sys__/idx.json`），不占 KV 配额
- 保存时同步写索引，**改完第一次搜索就能搜到**
- 索引只留每个文件前 8KB 正文；结果标「可能截断」，可点「深搜此文件」读全文验证
- 从控制台 / S3 / rclone 直接放进 R2 的文件：**文件名能搜到，正文不索引**，点一次「重建 / 更新正文索引」补齐
- 分享页只搜文件名与目录名（不泄露正文）

**分享**

- 生成只读口令链接，访客不能写、不能删、不能再分享
- **草稿树 `d/` 与已发布影子树 `__pub__/` 物理隔离**：改草稿不影响分享页，点「发布」才复制过去
- 「撤回」只是暂时收起（链接和内容都留着），「取消」才是立即失效
- 分享面板支持有效期；HTML 单文档按页面渲染但**脚本不执行**

**其它**

- **受保护文件夹**：标记后其内所有删除都要再输管理员密码，防手滑
- **PWA**：装到手机桌面，全屏无地址栏；图标与主题色自动生成（不依赖图片文件）
- 目录图标按层级配色，列表/目录树/搜索结果都带按类别着色的后缀徽标

## 数据存在哪

全在你的 R2 桶里，规则只有三条：

```
d/<路径>/            ← 零字节占位对象，代表「空文件夹」
d/<路径>/<文件名>     ← 真实文件（草稿树，管理端读写）
__pub__/<路径>/       ← 已发布副本（影子树，只有分享页读）
__sys__/idx.json     ← 全文搜索索引（不在文件目录里，不会被列出/删除）
```

KV 里存的（前缀互不干扰）：

| Key | 内容 | 删掉的后果 |
| --- | --- | --- |
| `share:<口令>` | 分享记录（路径 / 类型 / 有效期） | 分享链接全部失效 |
| `mp:<uploadId>` | 未完成的分片上传会话（24h 过期） | 大文件需重新开始 |
| `loginfail:<IP>` | 登录失败计数（10min 过期） | 锁定被重置 |
| `idx:v1` | 老版本的搜索索引（已迁到 R2） | 首次访问自动迁移并清理，删了不丢数据 |

想迁移或清空，直接在 R2 控制台操作即可。`__pub__/` 删掉等于把所有分享退回「待发布」，
在分享管理里点一次「全部发布」就能恢复。

## 安全

| 你设了什么 | 谁能进管理页 |
| --- | --- |
| 只设 `ADMIN_UUID` | **任何知道那串路径的人**。它等于密码，还会留在浏览器历史和分享记录里 |
| 再设 `PASSWORD` | 需要额外输密码；「退出」按钮也只在设了 `PASSWORD` 后出现 |

已经做的：

- 登录 Cookie 是 `HttpOnly + Secure + SameSite=Lax`，脚本读不到
- **登录失败限速**：同 IP 10 分钟错 8 次锁定，期间密码正确也拒绝（防爆破）
- **改 `PASSWORD` 立即让所有旧登录态失效** —— 怀疑泄露就改密码
- 分享链接一律只读，访客无法写入、无法再创建分享
- 所有路径归一化，`../` 被折叠，跳不出存储根目录
- **CSRF**：所有写操作校验 `Origin`，跨站请求直接 403
- **CSP**：只允许带随机 nonce 的内联脚本，外部脚本一律不加载（每次刷新 nonce 不同）
- 安全响应头：`nosniff`、`X-Frame-Options: DENY`、`noindex`（不被搜索引擎收录）
- **恶意文件沙箱**：上传的 HTML / SVG 不按原类型裸奔（HTML 走壳页面 + `?doc=1` + `script-src 'none'`，SVG 按纯文本）；预览走**不带 `allow-same-origin` / `allow-scripts`** 的 sandbox iframe
- **Markdown 不放行原始 HTML**：`.md` 里的 `<script>` 会显示成文字；链接只放行 `http(s)` / `mailto` / 站内相对路径
- 两层限速：Worker 内置（`RATE_LIMIT` / `DOWNLOAD_LIMIT`）+ 建议在控制台配 WAF Rate Limiting（跨节点硬限流）

> 为了媒体预览，CSP 的 `img-src` / `media-src` / `frame-src` 放行了 `blob:`。
> 字节都是同源接口经 `URL.createObjectURL` 来的，**不引外部域**，`object-src` 仍是 `'none'`。
> 不想要这个放宽，删掉 `appHtml` 里 CSP 的 `blob:` 即可 —— 代价是媒体预览失效，文本渲染不受影响。

还没做：**没有 2FA**，只靠密码。

## 上限与瓶颈

下面每一行都是**实测**，不是推测。

**上传**

| 情况 | 上限 | 撞到之后 |
| --- | --- | --- |
| 普通 PUT（≤ 8MB） | **100MB**（Cloudflare 请求体上限） | 413，前端提示「文件过大」 |
| 分片上传（> 8MB） | 4.995 TiB（R2 单对象上限） | 实际不会撞到；单片固定 8MB |
| 批量删除 / 移动 | **200 个/次** | 超出部分**静默丢弃**，如实回报实际处理了 200 |
| 多选上传 / 文件夹上传 | 个数不限（3 路 / 4 路并发） | 只是慢，单个失败不中断整批 |

**搜索**

| 项目 | 上限 | 撞到之后 |
| --- | --- | --- |
| 索引正文的文件数 | **3000 个** | 超出只按文件名搜 |
| 索引正文总量 | **1MB**（`INDEX_TEXT_CAP`） | 渐进降级：单文件片段从 8KB 缩到 512B |
| 单文件索引正文 | **512KB** | 不索引正文，文件照常保存 |
| 补扫 R2 对象数 | **5000 个** | 之后的文件按文件名也搜不到 |
| 单次返回 | 1 ~ 200（默认 60） | 走分页 |

> ⚠️ 索引满载（约 1.1MB）时单次搜索约 **10ms**，正好贴着免费版 CPU 红线，再多可能被 Cloudflare 打成 **1102**。
> 三个办法：①「重建 / 更新正文索引」清出不常搜的文件；② 升级付费版（30s CPU）；③ 谨慎调大 `INDEX_TEXT_CAP`（硬顶 1.5MB）。

**目录与请求频率**

| 项目 | 上限 | 说明 |
| --- | --- | --- |
| 目录树单层 | 500 个 | 超出折叠为「还有 N 个」，标记 `truncated` |
| 目录列表分页 | 按 `pageSize` | 总量不限（实测 600 个分 3 页） |
| 上传前同名比对清单 | 20000 个 | 超出只比对一部分 |
| 目录树「展开全部」 | 1200 个节点 | 提示逐级展开 |
| 管理端读请求 | 240 次/分/IP | 429 + `Retry-After`，前端自动退避 |
| 分享文件直连 | 60 次/分/IP | 429，按 IP 不按 token |
| 登录尝试 | 12 次 | 触发锁定 |

> 计数是**每个 Worker 实例各自维护的滑动窗口**，「尽力而为」。要硬限流请在 Cloudflare 控制台配 Rate Limiting 规则。
> 管理端**写**操作（上传/建目录的 PUT/POST/DELETE）不计入通用限速 —— 上传文件夹本来就是几百个请求；它们仍受密码 + CSRF 保护。

**平台天花板（与本项目无关）**

| 项目 | 免费版 | 付费版 |
| --- | --- | --- |
| 每日请求数 | 100,000/天 | 无限制 |
| 单次请求 CPU | **10ms** | 30 秒（可调至 5 分钟） |
| 内存 | 128MB | 128MB |
| 子请求数 | 50/次 | 10,000/次 |

## 常见坑

- **单文件真正的瓶颈是 100MB**，不是 R2 的 5TiB —— 请求体先撞墙。超大文件先压缩；分片只在 >8MB 时启用（R2 多段上传按 Class A 计费，小文件多段反而贵）。
- 删除文件夹是**递归且不可撤销**的；重要的目录先标成「受保护」。
- 单个文件夹里文件超过 **500** 个时，移动/重命名会被拒绝（R2 没有服务端复制，只能逐个搬），请分批。
- **从老版本升级，历史分享要补发一次**：老版本没有影子树，链接记录还在但内容没复制过去，打开「分享管理」点「全部发布」（已发布的会自动跳过，不会覆盖新版本）。
- **绑定变量名 `R2` / `KV` 不能改名**，代码里读的就是这两个名字；改了绑定**必须重新部署**才生效。
- 共用电脑上用完点「退出」，或把 `SESSION_DAYS` 设 `0`。
- 媒体预览靠浏览器原生能力，冷门编码（某些 `mkv`）可能播不了，用「下载」交给本地播放器。
- **POST 表单触发的下载**（少数网盘的导出接口）前端脚本认不出来，会由浏览器自己接走。
- 分享口令**就是访问凭证**，谁拿到都能看；不想再分享就点「取消」（立即失效）。

## 项目结构与 CI

```
worker.js                 Cloudflare Worker 主体（单文件，直接粘贴进控制台）
pages.zip                 Pages 版产物（上传 assets 用，内容必须 = 当前 worker.js）
mock.mjs                  内存版 R2 / KV：`node mock.mjs` 起本地服务器，或被测试 import
package.json              只为让 node 把 worker.js 当 ESM（type: module），不是部署用的 npm 项目
client/                   Flutter 原生客户端（自己画像素，不吃 WebView）
  core/                   纯 Dart：API 封装 / URL 规则 / 同步引擎（dart test）
  app/                    界面
.github/workflows/
  client-build.yml        client/** 变化时出 cfwtxt-android-apk / cfwtxt-windows-x64
```

流水线是「push 到 `main` 或对 `client/**` 发 PR 就自动跑」，产物在那次运行的 **Artifacts** 里
（GitHub 的产物和日志**需要登录**才能下）。想手动来一次：Actions → `client-build` → Run workflow。
